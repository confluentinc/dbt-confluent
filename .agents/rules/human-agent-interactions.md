# Human / Agent Interactions

  1. PR descriptions can be drafted by an agent, but should always be revised and finalized by a human before submission. PRs over-laden with automated content without human review are highly discouraged.
  2. Agents should never directly reply to humans in contexts such as PR comments, etc. A PR is an artifact by humans for humans with agents assisting in the process. It is demeaning for humans in a PR to interact with someone else's agent, be they the PR author or a reviewer. Agents should never directly comment on a PR using "/code-review --comment" or other tooling.
  3. Agents may be asked to author new issue descriptions, but these should always be reviewed and finalized by a human before submission, and the associated PR description should definitely err on human-authored content, never fully relying on agent-generated content.
  4. Humans should always validate agent findings when reviewing PRs, issue descriptions, or any other content generated by agents, ensuring accuracy and relevance before taking any action based on those findings, then decide the subset to describe to the human audience, using their own language to describe the issue. Agentisms should not make it into PR conversations.
