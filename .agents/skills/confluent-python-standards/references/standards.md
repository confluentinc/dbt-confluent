## Audit Thresholds

| Check | Pass | Warning | Fail |
|-------|------|---------|------|
| `pyproject.toml` present | ✅ | — | No file |
| `setup.py` or `setup.cfg` absent | ✅ | — | File exists |
| `uv.lock` present and committed | ✅ | Not committed | Absent |
| ruff `select` includes `E,F,I,UP,B` | ✅ | Missing ≤2 groups | Missing >2 groups |
| mypy `strict = true` or `ignore_missing_imports` | ✅ | Only `ignore_missing_imports` | No mypy config |
| `tests/unit/` directory exists | ✅ | — | Absent |
| `tests/functional/` (or `integration/`) exists | ✅ | — | Absent |
| Coverage floor ≥ 80% | ✅ | 60–79% | < 60% or not configured |
| `.pre-commit-config.yaml` with ruff + gitleaks | ✅ | ruff present, gitleaks absent | No pre-commit |
| `pip-audit` or OSV-Scanner in CI | ✅ | — | Absent |
| Changelog: towncrier OR conventional commits (not both) | ✅ | Both present | Neither |
| GitHub Actions pinned to SHAs | ✅ | Some floating tags | All floating tags |

## Ruff Rule Rationale

| Group | Replaces | Why include |
|-------|----------|-------------|
| `E,F,W` | pycodestyle + pyflakes | Core correctness — undefined names, unused imports |
| `I` | isort | Deterministic import ordering |
| `UP` | pyupgrade | Auto-modernize syntax (f-strings, `|` unions, etc.) |
| `B` | flake8-bugbear | Catches likely bugs: mutable defaults, broad excepts |
| `SIM` | flake8-simplify | Simplifies redundant `if`/`else`, ternaries |
| `PL` | pylint subset | Catches complexity and anti-patterns |
| `PTH` | — | Enforces `pathlib` over `os.path` |
| `PT` | flake8-pytest-style | Keeps pytest usage consistent |
| `RUF` | ruff-native | Extra rules unique to ruff |
| `D` | pydocstyle | Enforces docstring presence + Google/NumPy style |
| `S` | bandit | Security-focused checks (hardcoded passwords, `eval`, etc.) |

**Why not `C` (mccabe complexity)?** Complexity thresholds are noisy for data transformation code. Add `C90` only if you want cyclomatic complexity gating.

**Ignore `D203` + `D213`** to resolve the docstring-convention conflict (they contradict each other; pick one pair from `{D200,D212}` or `{D203,D213}`).

## Type Checking Setup

### mypy (`pyproject.toml`)

```toml
[tool.mypy]
namespace_packages = true
ignore_missing_imports = true   # drop once third-party stubs are stable
show_error_codes = true
pretty = true
strict = true                   # enables: disallow_untyped_defs, warn_return_any, etc.
```

For new projects: start with `strict = true` from day one.
For migration: add `disallow_untyped_defs = false` initially, tighten module-by-module.

**`py.typed` marker**: add an empty `py.typed` file to `src/<package>/` for any package consumed by other typed code. Without it, downstream `mypy` treats your package as untyped and falls back to `Any`.

### pyright / basedpyright (alternative)

```json
// pyrightconfig.json
{
  "include": ["src"],
  "typeCheckingMode": "strict",
  "pythonVersion": "3.10"
}
```

Pick **one** as the CI gate. Two gates is only justified for zero-dependency, widely-consumed libraries.

## CI Workflow Template

```yaml
# .github/workflows/ci.yml
name: CI

on:
  push:
    branches: [main]
  pull_request:

jobs:
  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@a5ac7e51b41094c92402da3b24376905139b0f3a  # pin to SHA
      - uses: astral-sh/setup-uv@f0ec1fc3b38f5e7cd731bb6ce540c5af426746bb
        with:
          enable-cache: true
      - run: uv run ruff check .
      - run: uv run ruff format --check .

  typecheck:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@a5ac7e51b41094c92402da3b24376905139b0f3a
      - uses: astral-sh/setup-uv@f0ec1fc3b38f5e7cd731bb6ce540c5af426746bb
        with:
          enable-cache: true
      - run: uv run mypy src

  unit-tests:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        python-version: ["3.10", "3.11", "3.12", "3.13"]
    steps:
      - uses: actions/checkout@a5ac7e51b41094c92402da3b24376905139b0f3a
      - uses: astral-sh/setup-uv@f0ec1fc3b38f5e7cd731bb6ce540c5af426746bb
        with:
          enable-cache: true
          python-version: ${{ matrix.python-version }}
      - run: uv run pytest tests/unit --cov=src --cov-fail-under=80

  functional-tests:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@a5ac7e51b41094c92402da3b24376905139b0f3a
      - uses: astral-sh/setup-uv@f0ec1fc3b38f5e7cd731bb6ce540c5af426746bb
        with:
          enable-cache: true
      - run: uv run pytest tests/functional

  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@a5ac7e51b41094c92402da3b24376905139b0f3a
      - uses: astral-sh/setup-uv@f0ec1fc3b38f5e7cd731bb6ce540c5af426746bb
        with:
          enable-cache: true
      - run: uv tool run pip-audit
```

**Rules:**
- Each job is a **separate named required check** — not one opaque "CI" job
- Pin all third-party Actions to a commit SHA (not a tag like `v4`)
- Audit with `zizmor` (GitHub Actions security scanner) periodically

## Pre-commit Config Template

```yaml
# .pre-commit-config.yaml
repos:
  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: v0.8.0
    hooks:
      - id: ruff-check
        args: [--fix]
      - id: ruff-format

  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v5.0.0
    hooks:
      - id: end-of-file-fixer
      - id: trailing-whitespace
      - id: check-toml
      - id: check-yaml
      - id: check-merge-conflict

  - repo: https://github.com/gitleaks/gitleaks
    rev: v8.21.0
    hooks:
      - id: gitleaks

  - repo: local
    hooks:
      - id: mypy
        name: mypy
        entry: uv run mypy src
        language: system
        pass_filenames: false
        types: [python]
```

Pre-commit must run the **exact same tools** as CI so `green local == green CI`.

## Supply Chain Details

Key practices for 2026+:

1. **Commit `uv.lock`** — hash-pinned, never let CI resolve fresh
2. **`pip-audit` or OSV-Scanner** in CI against the lockfile
3. **PyPI Trusted Publishing** (OIDC-based) for publishing — no long-lived tokens in CI secrets
4. **SBOM** (CycloneDX format) as a release artifact: `uv export --format cyclonedx > sbom.json`
5. **Cooldown window** (`uv`'s `exclude-newer` or internal proxy quarantine) — 2–3 day delay on brand-new package versions before CI can pull them
6. For CP4D / enterprise: route installs through Artifactory/Nexus mirror

## Changelog Mechanisms

Pick **one** per repo — never both.

### towncrier (preferred for Confluent Python repos)

```
# Add a fragment for each PR:
echo "Fix null handling in schema coercion." > changes/<issue-number>.bugfix

# At release time:
uv run towncrier --version 1.2.0
```

Fragment types: `breaking`, `feature`, `bugfix`, `doc`, `removal`, `misc`, `trivial`

### Conventional Commits + python-semantic-release

Commit messages: `feat: add Tableflow sink`, `fix: handle empty schema`, `chore: bump deps`
Release: `python-semantic-release version` reads commits and bumps SemVer automatically.

## Observability Patterns

For pipeline and SDK code (not pure library code):

```python
import logging
import json
import time
from opentelemetry import trace

# Structured JSON logger
class JSONFormatter(logging.Formatter):
    def format(self, record: logging.LogRecord) -> str:
        return json.dumps({
            "timestamp": time.time(),
            "level": record.levelname,
            "message": record.getMessage(),
            "run_id": getattr(record, "run_id", None),
            "logger": record.name,
        })

# Thread run_id through pipeline stages via context var or logger adapter
```

Use **OpenTelemetry** traces for pipeline/task execution, not a bespoke metrics format.

## CLI & SDK Conventions

For agent-facing tools especially:

- Build with **typer** or **click**, exposed via `[project.scripts]` entry points
- Provide `--json` / `--output json` mode on anything an agent might parse
- Use consistent, documented **exit codes**: `0` = success, `1` = user error, `2` = runtime error
- Type hints and docstrings are the source of truth for MCP/function-calling schema generators — treat them as functional requirements, not documentation
- Version the public surface independently from internal modules to avoid unnecessary major bumps

```python
# cli.py — typer example
import typer
import json

app = typer.Typer()

@app.command()
def run(
    topic: str = typer.Argument(..., help="Kafka topic name"),
    output: str = typer.Option("table", "--output", "-o", help="Output format: table|json"),
) -> None:
    """Run the pipeline stage."""
    result = {"topic": topic, "status": "ok"}
    if output == "json":
        typer.echo(json.dumps(result))
    else:
        typer.echo(f"Topic: {topic}  Status: ok")
```
