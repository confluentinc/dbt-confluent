Removed the `tableflow_api_key`/`tableflow_api_secret` profile fields. Every Tableflow operation (`enable`/`get`/`disable`) resolves the model's Kafka cluster id via CMK first, which requires a Global API key regardless -- a Tableflow-scoped key pair authenticates Tableflow's own routes but does nothing for that resolution, so it never actually let a profile use Tableflow without a Global key. Reintroducing a scoped credential option is tracked as a follow-up (#105), pending a `database_kafka_cluster_id` profile field to skip the CMK lookup.
