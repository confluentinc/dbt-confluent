Schema drift detection no longer reports a `with` option as drifted when Flink reports its value in a different form than the model wrote it. Durations and sizes are compared by value, so `'kafka.retention.time': '7 days'` matches the `7 d` Flink reports, and `'kafka.retention.size': '1024 mb'` matches `1 gb`; case is ignored, so `'COMPACT'` matches `compact`. Before, these models reported drift on every run until rebuilt with `--full-refresh`. A change that only alters the case of a value is not detected. See MATERIALIZATIONS.md#with-options-drift.
