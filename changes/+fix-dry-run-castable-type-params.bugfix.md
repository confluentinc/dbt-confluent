Fix `dry_run.try_get_castable_type` silently dropping a unit test's inferred `DECIMAL` precision when only one of precision/scale came back from a dry run (fell through to bare `DECIMAL` instead of `DECIMAL(p)`). Parameter reconstruction now checks which of length/precision/scale a `ColumnTypeDefinition` actually reports rather than checking type-name allowlists, so it degrades gracefully instead of dropping known info.
