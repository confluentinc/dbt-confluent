`streaming_table` now runs dbt's contract check before re-submitting a missing or stopped INSERT, as it already did before `create table`, whatever `on_schema_drift` is set to. A restart now fails with dbt's contract error if the SELECT and the yml `columns` disagree, including an adopted table whose yml lists no `columns` or only some of them: list every SELECT column in the yml to fix it. Each restart also makes two more schema queries.
