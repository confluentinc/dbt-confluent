Replace `statement_name_prefix` with an optional `resource_name_prefix` that isolates environments (e.g. developers) sharing one cluster. When set, it is prepended to every topic and statement name, including explicit `alias` and `statement_name`. It defaults to empty, so generated statement names drop the old `dbt-` prefix (`dbt-<project>-<model>` becomes `<project>-<model>`): the next run starts new statements and the old ones keep running until stopped. Profiles setting `statement_name_prefix` now fail to load; note that moving its value to `resource_name_prefix` also prefixes topic names.
