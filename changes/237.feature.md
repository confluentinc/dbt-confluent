Make `organization_id` optional in the profile when using `auth: oauth` or a Global API key. With a Global API key it is inferred when the key can see exactly one organization, and the connection fails, asking you to set `organization_id`, if it can see several. With `auth: oauth` the login's default organization is used, so set `organization_id` if you belong to several organizations and your environment is in a different one. A supplied `organization_id` is verified against the credential. It is still required with a Flink-region API key. This inference behavior is expected to be simplified in a future release; see the README's "Organization ID" section.
