Add an optional `resource_name_prefix` profile setting that isolates topics and statements in a shared environment. It is prepended to statement names, in front of `statement_name_prefix`, and to topic names with hyphens as underscores. For example, with `resource_name_prefix: alice-` the statement becomes `alice-dbt-<project>-<model>` and the topic `alice_orders`. Names are unchanged when it isn't set.
