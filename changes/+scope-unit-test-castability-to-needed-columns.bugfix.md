Fix a unit test failing because the tested model selects a column of an otherwise-unsupported type (e.g. `ARRAY`) that the unit test's `expect` block never actually references. `get_tested_model_columns`/`_dry_run_columns` now only require `try_get_castable_type`'s stricter cast-ability guarantee for the columns a fixture's `expect` rows actually name; every other column just needs a valid DDL type (`dry_run.get_ddl_type`), since dbt-core's own fixture rendering never looks those up anyway.
