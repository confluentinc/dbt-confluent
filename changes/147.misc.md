Mark tests `unit` or `functional` automatically by directory, so `pytest -m unit` and `pytest -m functional` select a suite (unknown markers are now an error). The `unit` poe task now runs `pytest -m unit`, a new `functional` task runs `pytest -m functional`, and a new `cicd` task runs everything Semaphore does (lint, changelog check, build, tests), e.g. for a pre-push hook. Semaphore's test job now just runs `poe unit`. Functional-only fixtures moved from `tests/conftest.py` to `tests/functional/conftest.py`.
