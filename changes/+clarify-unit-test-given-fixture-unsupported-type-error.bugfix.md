Fix a unit test's `given` fixture failing with a raw, unactionable Flink SQL parse error (`Encountered '[' ...`) when a row supplies a value for a column of an unsupported constructed type (`ARRAY`/`MAP`/`ROW`/`MULTISET`/interval) - dbt-core's own fixture rendering has no way to emit a valid literal for one. `insert_unit_test_fixture` now catches that failure and, when the input relation actually has such a column, re-raises naming it explicitly (with the original error preserved underneath) instead of leaving the user to decode a bare parser error.
