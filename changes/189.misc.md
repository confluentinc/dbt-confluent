The schema drift check now reads only what it needs from `INFORMATION_SCHEMA`: `table` and `streaming_table` models no longer read the existing table's columns (only its distribution columns, when `distributed_by` is set), and a model that falls back to the temporary table no longer reads `TABLES` and `TABLE_OPTIONS` twice. If `INFORMATION_SCHEMA.TABLES` doesn't have the existing table yet, the check now fails with a retriable error rather than reporting drift.
