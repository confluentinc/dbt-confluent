Add a `statement_properties` config for `streaming_table` to set Flink SET-style statement properties. See the [SET Statement](https://docs.confluent.io/cloud/current/flink/reference/statements/set.html) documentation for available options. Applies to the long-running INSERT statement only, not the separate DDL statement (whose options can be configured with the existing 'with' configuration option). See MATERIALIZATIONS.md.
